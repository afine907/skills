# 复盘记录模板

> 写入 `.claude/retrospectives/YYYY-MM-DD-<简短描述>.md`

```markdown
# 复盘记录 YYYY-MM-DD

## 1. 事件回顾
- **用户说了什么**: [原文引用]
- **AI 做错了什么**: [具体行为]
- **正确做法应该是什么**: [期望行为]

## 2. 根因分析
- **直接原因**: [为什么这次做错了]
- **根本原因**: [CLAUDE.md 缺规则 / rules 写得不好 / 没有记忆 / skill 没覆盖]

## 3. 修复措施
- **修改了哪个文件**: [文件路径]
- **新增/修改了什么内容**: [具体变更]
- **内容预览**:

  ```markdown
  [写入的内容]
  ```

## 4. 验证
- [ ] 未来遇到类似场景时，这条规则会被触发
- [ ] 写入内容简洁可操作（< 5 行）
```
