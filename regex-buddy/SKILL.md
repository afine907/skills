# Regex Buddy — 正则表达式 Agent

自然语言描述 → 正则 + 逐段解释 + 测试用例，一次输出。

## 工作流程

```
描述 → 选构造策略 → 编写正则 → 逐段解释 → 生成测试用例 → 标记边界
```

## 构造策略

| 场景 | 推荐策略 | 示例 |
|------|----------|------|
| **精确匹配** | 最简模式 + 边界锚定 | `^[a-z]+$` |
| **提取** | 捕获组 `()`，避免贪婪 | `id=(\d+)` |
| **校验** | 全串匹配 + 前瞻/后顾 | `^(?=.*[A-Z])(?=.*\d).{8,}$` |
| **替换** | 捕获组 + 反向引用 | `s/(\d{4})-(\d{2})/$2-$1/` |
| **分割** | 用 `[^...]+` 取反集 | `[^,]+` 匹配 CSV 字段 |

## 最佳实践

| 规则 | 说明 |
|------|------|
| **避免贪婪** | 用 `*?` `+?` 替代 `*` `+`，除非确定要贪婪 |
| **锚定边界** | 校验用 `^...$`，搜索不需要 |
| **命名捕获组** | `(?P<name>...)` Python / `(?<name>...)` PCRE |
| **转义要完整** | `. \| ( ) [ ] { } ^ $ * + ?` 这些都需要转义 |
| **不要过度复杂** | 多个简单正则比一个巨无霸好维护 |

## 快速使用

```
# 写正则
写个正则匹配中国大陆手机号

# 校验正则
帮我校验这个正则：/^[\w\.-]+@[\w\.-]+\.\w+$/

# 解释正则
解释一下这个正则什么意思：/^(?=.*[A-Z])(?=.*\d).{8,}$/

# 提取内容
从这段文本里提取所有 URL：...
```
