# Tech Spec — 技术方案设计技能

根据需求文档输出结构化技术方案，用于技术评审和团队对齐。


## Goal

根据需求文档输出技术方案设计，包含架构设计、模块划分、接口定义、数据模型、技术选型、风险评估

## Trigger

- 用户要求"写技术方案"、"技术设计"、"系统设计"
  - 需求评审后需要技术实现方案
  - 重构前需要技术方案论证

## Workflow

```
输入 → 处理 → 输出
```
## 工作流程

```
需求分析 → 方案设计 → 技术选型 → 详细设计 → 风险评估 → 输出文档
```

## 设计原则

1. **简单优先** — 能用简单方案解决的不要过度设计
2. **可扩展** — 设计时考虑未来3-6个月的扩展
3. **可观测** — 关键路径必须有日志、指标、链路追踪
4. **容错设计** — 外部依赖必须有超时、重试、降级
5. **安全第一** — 认证、授权、加密、审计缺一不可
