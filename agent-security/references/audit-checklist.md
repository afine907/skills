# Agent 安全审计清单

## 部署前审计

### 1. 威胁建模

- [ ] 已识别所有输入源（用户输入、工具返回、外部数据）
- [ ] 已评估每个输入源的可信度
- [ ] 已识别 Agent 可执行的所有操作
- [ ] 已评估每个操作的风险等级和爆炸半径
- [ ] 已制定针对每种威胁的缓解措施

### 2. 权限配置

- [ ] 所有工具已分配到正确的权限层级
- [ ] 默认权限是"拒绝"（deny by default）
- [ ] 每个 Agent 使用独立的 IAM 角色
- [ ] 权限配置文件已通过安全审查
- [ ] 权限变更流程已建立

### 3. HITL 门禁

- [ ] Tier 1 操作已配置确认门禁
- [ ] Tier 2 操作已配置审批门禁
- [ ] 长任务已配置检查点门禁
- [ ] 低置信度场景已配置升级门禁
- [ ] 门禁超时策略已定义

### 4. 注入防御

- [ ] 输入消毒已实现（4 层防御）
- [ ] 系统提示已加固（指令层级、分隔符）
- [ ] 上下文隔离已实现（消息角色、来源标记）
- [ ] 输出验证已实现（泄露检测、PII 过滤）
- [ ] 已用已知注入向量测试

### 5. 数据保护

- [ ] PII 检测已启用
- [ ] 数据流控制已配置
- [ ] 敏感数据分类标签已定义
- [ ] 数据访问日志已启用
- [ ] 数据保留策略已定义

### 6. 资源控制

- [ ] 步骤硬上限已设置（代码级）
- [ ] 成本上限已设置（Token 和美元）
- [ ] 断路器已启用（工具调用级别）
- [ ] 循环检测已启用
- [ ] 限流已配置（每分钟调用次数）

### 7. 日志与审计

- [ ] 所有工具调用已记录
- [ ] 所有 HITL 门禁事件已记录
- [ ] 所有安全事件已记录
- [ ] 日志包含足够的上下文（session_id, trace_id, step_number）
- [ ] 日志保留期已定义

### 8. 回滚能力

- [ ] 关键操作支持回滚
- [ ] 补偿动作已注册（Saga 模式）
- [ ] 紧急停止机制已实现
- [ ] 回滚流程已测试

### 9. 测试覆盖

- [ ] Prompt Injection 测试（10+ 攻击向量）
- [ ] 权限越权测试
- [ ] 数据泄露测试
- [ ] 资源耗尽测试
- [ ] 工具滥用测试
- [ ] 红队测试（人工对抗）

### 10. 监控告警

- [ ] 安全事件告警已配置
- [ ] 异常行为告警已配置
- [ ] 成本飙升告警已配置
- [ ] 告警响应流程已定义
- [ ] 告警联系人已配置

## 定期审计（每月）

- [ ] 审查权限使用情况，收回不再需要的权限
- [ ] 审查安全事件日志，识别模式
- [ ] 更新注入防御模式（新的攻击向量）
- [ ] 验证 HITL 门禁的有效性
- [ ] 更新威胁模型（新的工具、新的功能）
