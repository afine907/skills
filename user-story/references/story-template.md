# 用户故事模板库

## 通用模板

### CRUD 操作

```markdown
## US-{编号}: {资源} - 创建

**作为** {角色}
**我希望** 创建新的{资源}
**以便** {业务价值}

### 验收标准
- Given 我有创建权限
- When 填写必填字段并提交
- Then {资源}创建成功，返回唯一ID
- And 出现在{资源}列表中
```

```markdown
## US-{编号}: {资源} - 查询

**作为** {角色}
**我希望** 查询{资源}列表
**以便** {业务价值}

### 验收标准
- Given 系统中存在{资源}数据
- When 打开{资源}列表页
- Then 显示分页列表，默认按创建时间倒序
- And 支持按{字段}筛选
- And 支持按{字段}搜索
```

### 认证授权

```markdown
## US-{编号}: 用户登录

**作为** 注册用户
**我希望** 通过邮箱密码登录
**以便** 访问我的个人数据

### 验收标准
- Given 用户已注册
- When 输入正确邮箱和密码
- Then 登录成功，跳转到首页
- And 显示用户头像和昵称

- Given 用户已注册
- When 输入错误密码
- Then 提示"邮箱或密码错误"
- And 连续5次错误后锁定30分钟
```

```markdown
## US-{编号}: 权限控制

**作为** {角色}
**我希望** 只能访问我有权限的功能
**以便** 保证数据安全

### 验收标准
- Given 用户角色为 {角色}
- When 访问无权限的页面
- Then 显示403页面或跳转到首页
- And API 返回 403 FORBIDDEN
```

### 搜索过滤

```markdown
## US-{编号}: 全文搜索

**作为** {角色}
**我希望** 通过关键词搜索{资源}
**以便** 快速找到目标数据

### 验收标准
- Given 系统中存在匹配数据
- When 输入关键词并搜索
- Then 返回匹配结果，关键词高亮
- And 显示匹配数量和耗时
- And 支持分页浏览

- Given 搜索结果为空
- When 输入无匹配的关键词
- Then 显示"未找到相关结果"
- And 提供搜索建议
```

### 文件上传

```markdown
## US-{编号}: 文件上传

**作为** {角色}
**我希望** 上传{文件类型}文件
**以便} {业务价值}

### 验收标准
- Given 文件格式为 {格式列表}
- When 选择文件并上传
- Then 文件上传成功，显示文件名和大小
- And 文件大小不超过 {限制}

- Given 文件格式不在允许列表
- When 选择非法格式文件
- Then 提示"仅支持 {格式} 格式"

- Given 文件大小超过限制
- When 选择超大文件
- Then 提示"文件大小不能超过 {限制}"
```

### 导出报表

```markdown
## US-{编号}: 数据导出

**作为** {角色}
**我希望** 导出{数据}为 Excel/CSV
**以便} 进行离线分析

### 验收标准
- Given 有可导出的数据
- When 点击导出按钮
- Then 生成 Excel/CSV 文件并下载
- And 包含所有可见列
- And 数据量超过10000条时异步导出并通知

- Given 当前筛选条件有结果
- When 在筛选后点击导出
- Then 仅导出筛选后的数据
```
